## Yapı

```

├── Numpy/                 # Numpy temelleri, orta ve ileri seviye çalışmalar
├── Pandas/                 # Pandas temelleri ve veri temizleme
├── Regresyon-Analizi/      # Logistic ve Polynomial regresyon
└── ML-Algoritmalari/       # SVM, Unsupervised, Ridge/Lasso, Karar Ağaçları
```
